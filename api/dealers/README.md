# dealers — Showroom, đại lý, trạm sạc

Owner: **R2a**.

Mạng lưới điểm vật lý: showroom, nhà phân phối, xưởng dịch vụ, trạm sạc.
Có toạ độ, khu vực phụ trách, giờ mở cửa, dịch vụ cung cấp tại từng điểm.

Là dữ liệu nền cho `testdrive/` (chọn nơi lái thử), `inventory/` (xe nằm ở đâu)
và `orders/` (nhận xe ở đâu) — nên giữ ổn định, đổi schema phải báo R2b.
