# orders — Đặt cọc đến giao xe

Owner: **R2b**.

Vòng đời đơn: chọn cấu hình → đặt cọc → hợp đồng → thanh toán → đăng ký → giao xe.

Luật quan trọng: khi tạo đơn phải **chụp snapshot** giá, ưu đãi đang áp dụng và
cấu hình xe vào chính đơn hàng. Sau đó đơn không đọc lại `pricing/`. Giá hay
khuyến mãi thay đổi về sau không được làm đổi đơn đã chốt.
